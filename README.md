# ⌨️ Typing Speed Tester

A web-based application designed to measure and track your typing speed (WPM) and accuracy in real-time.

## 🚀 Features
•⁠  ⁠Live Words Per Minute (WPM) tracking
•⁠  ⁠Accuracy percentage calculation
•⁠  ⁠Restart button to try again

## 🛠️ Built With
•⁠  ⁠HTML5
•⁠  ⁠CSS3
•⁠  ⁠JavaScript (Vanilla)

## 📖 How to Run
Simply open ⁠ index.html ⁠ in any modern web browser.
